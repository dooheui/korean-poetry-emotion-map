# 작품별 대표 감정 이미지

수록 시 20편의 사전 가중치 50% 장면 규칙을 참고해 2026-11-29 이미지 생성 도구로 사전 제작한 수채화 일러스트입니다.

- `*-w50.webp`: 웹앱에서 표시하는 그림 20장. 이미지 크기는 유지하고 웹용으로 인코딩했습니다.
- `manifest.json`: 작품 ID·제목·주요 감정·보조 감정·인물 유무·파일 대응.
- `prompts.json`: 각 이미지의 생성 프롬프트.

실내 나무·나뭇가지를 제외하고 큰 창문, 부드러운 의자와 자연스러운 인체를 요청했습니다. 인물은 시인 초상이 아닙니다. 색 혼합량·자세·소품이 분석 비율이나 기존 Canvas의 수치와 정밀하게 대응하는 것은 아닙니다. 원래 시의 실제 장면을 재현한 것도 아닙니다.

모든 감정 사전 반영 비율에서 작품별로 동일한 대표 이미지를 사용합니다. 분석 수치와 추천·지도는 선택한 반영 비율에 따라 달라집니다. 사이트에서 외부 이미지 생성 API를 호출하지 않습니다.
