# 시의 결 — 한국 근대시 감정 분석

시를 읽으며 느낀 감정과 낱말을 세어 얻은 감정은 얼마나 다를까요? 이 웹앱은 한국 근대시 20편을 감정 사전으로 분석하고, 작품을 읽고 정한 해석과 비교합니다. 감정 비율만 보는 데서 끝나지 않고, 어떤 시어와 구절에서 결과가 나왔는지 살펴볼 수 있도록 만들었습니다.

- 웹앱: [시의 결](https://dooheui.github.io/korean-poetry-emotion-map/)
- GitHub 저장소: [dooheui/korean-poetry-emotion-map](https://github.com/dooheui/korean-poetry-emotion-map)
- 과목: 감성컴퓨팅
- 작성자: 박두희
- 문서 기준일: 2026년 11월 29일입니다.
- 분석 기준: 감정 사전의 시어 감지와 작품별 해석 프로필을 사용합니다.

## 1. 사용 방법

별도 설치나 로그인 없이 웹앱 주소를 열면 이용할 수 있습니다.

1. 시를 선택하거나 제목·시인으로 검색합니다. 휴대폰에서는 목록을 가로로 넘길 수 있습니다.
2. 시 본문과 지배 정서를 보고 감정 이름이나 행을 누르면 감지한 시어·근거를 확인할 수 있습니다. ‘넓게 읽기’로 원문을 확대할 수 있습니다.
3. 감정 프로필·행별 흐름·최종 분석 다이어그램을 살펴보고, 감정 이미지를 PNG로 저장하거나 외부 AI 이미지용 프롬프트를 복사할 수 있습니다.
4. 비슷한 시 3편을 추천받고 감성 지도·전체 비교(히트맵)에서 작품을 비교합니다. 히트맵은 칸 선택이나 방향키로 수치를 확인합니다.
5. ‘계산과 해석 사이’에서 사전 가중치 0%·50%·100%를 비교하고 적용합니다. ‘상세 비교·메모’에서는 근거를 확인하고 메모를 남길 수 있습니다.
6. ‘내 시 분석’에 직접 시를 입력하면 감정 비율·행별 분석·유사 작품을 확인할 수 있습니다.

### 화면 구성과 이동 순서

화면 오른쪽의 결과는 다음 순서로 표시됩니다. 상단 목차도 같은 순서이며, 목차를 선택하면 해당 구간으로 이동합니다.

| 화면 순서 | 구간 | 배치 |
|---|---|---|
| 1 | 시 본문 · 지배 정서 | 좌우 2단 |
| 2·3 | 감정 프로필 · 행별 감정 흐름 | 나란히 2단 |
| 4 | 최종 분석 다이어그램 | 전체 폭. ‘시어 → 감정 → 주제’를 부제로 표시 |
| 5 | 감정 이미지 | 전체 폭 |
| 6 | 비슷한 감성의 시 | 전체 폭 |
| 7·8 | 감성 지도 · 전체 비교 | 감성 지도가 먼저 나오며, 넓은 화면에서는 나란히 배치. 1366px에서는 위아래 배치 |
| 이후 | 계산과 해석 사이 → 상세 비교·메모 → 내 시 분석 → 범주와 사전 | 순서대로 배치 |

화면 폭이 좁을 때는 두 단 구간도 세로로 재배치할 수 있습니다. 목차는 가로로 넘겨 탐색할 수 있습니다. ‘최종 분석 다이어그램’이라는 제목은 확대 창에서도 사용합니다.

감정어가 없다고 감정이 없는 시는 아닙니다. 감지 결과가 없으면 비율이나 추천을 임의로 만들지 않고 안내합니다. 「절정」을 사전 100%로 볼 때도 같은 원칙을 적용합니다.

‘이 시 공유하기’는 작품과 가중치를 담은 주소를 복사합니다. 독자 메모는 현재 기기의 브라우저에만 저장하며 공유 주소에 포함하지 않습니다. 직접 입력한 글은 저장하거나 외부로 보내지 않습니다. 외부 글꼴을 불러오지 못하면 기기의 기본 글꼴로 표시합니다.

## 2. 수록 작품과 출처

## 3. 감정 범주와 분석 방법

### 감정 범주

### 사전으로 계산하는 방법

기계학습 모델 대신 브라우저의 JavaScript가 감정 사전을 찾아 계산합니다. 현재 사전에는 총 159개 시어가 있습니다. 범주마다 11~33개를 사용합니다. 전체 목록은 앱의 ‘범주와 사전’과 이 문서의 부록에 있습니다.

1. 시를 줄바꿈으로 나눕니다. 빈 줄은 연 구분에 쓰고 분석 행에서는 제외합니다.
2. 모든 시어를 긴 것부터 하나의 정규식으로 찾습니다. ‘구슬픈’을 센 자리에서 ‘슬픈’을 다시 세지 않습니다. 같은 말이 다른 곳에 반복되면 등장한 만큼 셉니다.
3. 행마다 감지 시어와 감정별 개수를 기록합니다. 시 전체의 감정 비율은 ‘해당 감정의 감지 횟수 ÷ 전체 감지 횟수’로 구합니다.
4. 감지가 0회이면 사전 비율은 모두 0으로 두고 지배 정서를 정하지 않습니다.

차단어 ‘바라보’·‘바라다보’는 ‘바라보다’를 희망의 ‘바라다’로 세는 것을 막습니다. ‘고요’는 낱말 첫머리에서만 세므로 ‘그림자라고요’는 제외하고 ‘고요한 밤’은 셉니다. 옛한글과 반복 부호는 분석용 사본에서만 바꾸고, 화면 본문과 감지 위치는 원래 표기를 따릅니다.

### 해석 프로필과 가중치

사전이 놓치는 어조·반어·상징을 함께 살펴보기 위해 작품마다 해석 프로필을 두었습니다. 프로필은 각 감정이 작품에서 얼마나 중심적인지 0~1로 정한 값입니다. AI 초안과 AI 재검토가 포함된 해석 값이며, 정답이나 자동 감정 분류 모델의 예측값은 아닙니다.

강도는 약함(0.1~0.2), 보조(0.3~0.4), 뚜렷함(0.5~0.6), 중심(0.7~0.8), 지배(0.9~1.0)로 나누고, 원래 값은 0.1 단위를 사용합니다. 기준표가 수치의 타당성을 검증해 주는 것은 아닙니다. 작품별 근거 구절·어조·구조와 함께 읽어야 합니다. 다른 읽기가 가능한 항목에는 ‘잠정’과 대안 해석을 표시했습니다.

계산할 때는 프로필의 합이 1이 되도록 나눈 뒤 사전 비율과 섞습니다.

`결합 결과 = 정규화((1 − 사전 가중치) × 해석 프로필 + 사전 가중치 × 사전 비율)`

사전 비중 0%는 해석 프로필만, 100%는 사전만 반영합니다. 프로필이 없는 글은 사전으로만 분석합니다. 「절정」처럼 감지가 없으면 100% 미만의 결과는 프로필에서만 나옵니다. 화면에서 이 점을 따로 안내합니다.

값이 있는 경우 표시 비율의 합은 100.0%가 되도록 반올림합니다. 동률은 반올림 전 값으로 판단하고 공동 1위 감정을 함께 보여 줍니다. 대표 색은 범주 순서상 앞선 감정의 색을 사용합니다. 히트맵의 정수 합계는 100과 다를 수 있으며 실제 차이를 표 아래에 안내합니다.

### 추천과 감성 지도

추천은 두 감정 비율의 구성이 얼마나 닮았는지 코사인 유사도로 비교합니다. 수록 작품은 같은 가중치의 결과끼리 비교하고 자기 자신을 제외한 상위 3편을 보여 줍니다. 값이 모두 0인 작품은 비교에서 제외합니다. 직접 입력한 글은 프로필이 없으므로 수록작의 사전 비율과 비교합니다.

PCA 지도는 10개 감정 비율에서 작품들의 평균을 뺀 뒤 차이가 큰 두 방향으로 펼쳐 놓습니다. 축을 대표하는 감정과 두 축이 보여 주는 분산의 비율을 함께 설명합니다. 지도에서 가까워도 시의 주제나 문학적 의미까지 같다는 뜻은 아닙니다.

## 4. 계산과 해석이 달라지는 사례

아래 수치는 현재 분석 엔진의 계산 결과입니다. ‘결합’은 사전 50% 기준입니다. 감정 비율은 감정 구성이지 정확도나 그 감정일 확률이 아닙니다.

### 사례 1. 「절정」: 감정어가 없어도 정서는 드러납니다

- 계산: 8행 전체에서 감지 0회입니다. 사전 100%에서는 비율·지배 정서·추천을 만들지 않습니다. 결합 결과는 프로필에서만 나와 희망·의지 53.3%, 불안·공포 26.7%, 슬픔 20.0%입니다.
- 해석: ‘겨울은 강철로 된 무지갠가보다’는 극한 상황에서도 희망을 읽는 역설로 볼 수 있습니다.
- 원인: 사전은 ‘채찍’·‘칼날’ 같은 이미지와 작품 전체의 전환을 이해하지 못합니다.
- 개선과 한계: 감지 없음과 프로필만 반영한 상태를 안내하도록 구현했습니다. 이미지어를 감정에 고정하거나 임의의 비율을 만들지는 않았습니다. 문장과 시 전체를 읽는 분석은 앞으로의 과제입니다.

### 사례 2. 「남으로 창을 내겠소」: 웃음이 항상 기쁨은 아닙니다

- 계산: 12행 ‘웃지요’에서 ‘웃지’ 1회만 감지해 사전 결과가 기쁨 100%입니다. 결합은 기쁨 60.7%, 평온 32.2%, 사랑 7.1%입니다. 프로필만 보면 평온 64.3%입니다.
- 해석: ‘왜 사냐건 / 웃지요’는 들뜬 기쁨보다 삶을 담담하게 받아들이는 웃음으로 읽을 수 있습니다.
- 원인: 웃음이라는 반응만 세고 앞 문장의 질문과 어조를 읽지 못합니다. 한 낱말만 있어도 비율로 바꾸면 100%가 됩니다.
- 개선과 한계: 감지가 1~2회이면 적은 근거에 좌우된다는 안내를 구현했습니다. 웃음의 뜻까지 자동으로 구별한 것은 아닙니다.

### 사례 3. 「별 헤는 밤」: 부정된 걱정도 세어집니다

- 계산: 3행 ‘나는 아무 걱정도 없이’의 ‘걱정’을 불안·공포로 셉니다. 전체 8회 중 1회이므로 사전 비율은 12.5%, 결합 비율은 6.3%입니다.
- 해석: 해당 구절은 걱정이 없는 상태를 말합니다.
- 원인: 사전은 ‘없이’가 앞의 감정을 부정하는 관계를 읽지 못합니다.
- 개선과 한계: 실제 구절과 원인을 검증 카드에 표시했습니다. ‘없다’가 나오면 앞 감정을 모두 지우는 규칙은 다른 구절을 잘못 처리할 수 있어 넣지 않았습니다. 부정의 범위를 구별하는 분석이 필요합니다.

### 사례 4. 「빼앗긴 들에도 봄은 오는가」: 마지막 행의 전환을 놓칩니다

- 계산: 전체 6회 중 기쁨 5회, 슬픔 1회로 사전 기쁨은 83.3%입니다. 결합에서도 기쁨 50.9%가 가장 높습니다.
- 해석: 첫 행부터 빼앗긴 땅임을 밝히고, 마지막 행에서 그 상실을 다시 짚어 앞의 밝은 정경을 다르게 읽게 합니다.
- 원인: 모든 행의 낱말을 같은 무게로 세고 시의 마지막 전환을 반영하지 못합니다.
- 개선과 한계: 사전 결과와 상실을 중심으로 한 해석을 나란히 보여 줍니다. 마지막 행에 무게를 더 주는 방법은 다른 작품에서도 타당한지 검증해야 하므로 제안으로 남겼습니다.

### 사례 5. 「그날이 오면」: 기쁨의 울음을 슬픔으로 셉니다

- 계산: 전체 5회 중 기쁨 4회, 슬픔 1회로 사전 결과는 기쁨 80.0%, 슬픔 20.0%입니다. 10행의 ‘울며’가 슬픔으로 잡힙니다.
- 해석: ‘울며 뛰며 딩굴어도’는 넘치는 기쁨의 몸짓으로 읽힙니다. 작품은 아직 오지 않은 날을 기다리는 의지도 담고 있습니다.
- 원인: 울음의 이유와 가정 표현을 읽지 못합니다.
- 개선과 한계: 현재 사전에는 ‘죽사’ 같은 죽음의 상황어를 포함하지 않지만, ‘울며’의 중의성은 남아 있습니다. 표출어의 한계로 기록하고 프로필과 비교합니다.

### 사례 6. 「나는 왕이로소이다」: 알려진 오탐을 규칙으로 줄였습니다

- 오탐 가능성: ‘모가지 없는 그림자라고요’의 어미 속 ‘고요’를 평온으로 잘못 셀 수 있습니다.
- 적용한 규칙: ‘고요’는 낱말 첫머리에서만 셉니다. ‘그림자라고요’·‘좋고요’는 제외하고 ‘고요한 밤’·‘고요히’는 셉니다.
- 현재 계산: 감지 34회이며 사전 슬픔은 88.2%, 결합 슬픔은 72.2%입니다. 이 비율은 사전 전체를 적용한 결과이며, ‘고요’ 규칙 하나만의 효과를 뜻하지 않습니다.
- 남은 한계: ‘시름없이’는 두 뜻이 있어 어느 쪽으로 읽느냐에 따라 판단이 달라집니다. 특정 오탐을 줄여도 문맥 전체가 해결되는 것은 아닙니다.

## 5. 한계와 개선 방향

사전은 계산 과정이 분명하고 근거를 찾기 쉽지만, 부분 문자열·중의성·부정·반어를 온전히 구별하지 못합니다. 화자의 감정과 다른 등장인물의 감정도 섞일 수 있습니다. 감지 횟수와 비율만으로 시의 감정 강도나 분석의 정확도를 판단할 수는 없습니다.

해석 프로필도 하나의 읽기일 뿐입니다. 현재는 AI 초안과 AI 재검토가 포함되어 있고 여러 독자가 합의한 정답이 없습니다. 원문·서지의 미확인 사항도 남아 있습니다. 감정 이미지는 분석값을 색·날씨·빛·인물로 옮긴 상징이며 시에 실제로 등장하는 장면의 재현은 아닙니다.

앞으로는 원전 지면 대조를 보완하고, 여러 독자가 같은 구절을 어떻게 읽는지 비교하고 싶습니다. 부정과 반어를 고려한 문장 분석을 추가한다면 지금 사전 방식과 같은 작품에서 비교해 차이를 확인할 필요가 있습니다.

## 6. AI 도구 사용 내역

| 도구 | 사용한 부분 |
|---|---|
| Claude | HTML·CSS·JavaScript 구현, 시 데이터와 출처 정리, 감정 사전·프로필·해석 초안, 오류 수정과 자동 검사에 사용했습니다. 서지 자료와 해석 설명 검토에도 사용했습니다. |
| ChatGPT | 과제 요구사항 대조, 화면과 코드 검토, 수정 요청 프롬프트 작성, 계산 수치 확인, 발표 연도 자료 조사, README 구성과 문장 정리에 사용했습니다. 감정 이미지는 처음에 Claude를 활용해 코드로 구현했으나 원하는 시각적 표현이 나오지 않아, ChatGPT를 활용해 작품별 대표 이미지 20장을 제작하고 웹앱에 연결했습니다. |

AI가 기억해서 쓴 시를 원문으로 사용하지 않고 작품별 출처와 판본을 기록했습니다. 다만 출처를 적었다는 것만으로 모든 원전 대조가 끝난 것은 아니므로 확인 범위를 함께 남겼습니다. 화면과 기능의 직접 사용 기록은 아래에 적었습니다. 해석에는 AI 초안과 AI 재검토가 포함되어 있으며, 이를 학생의 최종 판단이 끝난 해석이나 객관적으로 검증된 감정값으로 표시하지 않았습니다.

## 7. 구현한 기능

| 구분 | 구현 내용 |
|---|---|
| 필수 F-01~F-05 | 시 목록, 본문 전체와 시어 강조, 감정 비율, 행별 감정, 지배 정서·주제·해석을 제공합니다. |
| 기본 F-06~F-11 | 감정 프로필(레이더 차트), 행별 흐름 차트, 최종 분석 다이어그램(시어–감정–주제 연결도), 추천 3편, 히트맵, 직접 입력한 시 분석을 제공합니다. 기본 6개를 모두 구현했습니다. |
| 확장 F-12~F-14 | PCA 감성 지도, 창가 감정 이미지, 사전·해석 가중치 조절을 제공합니다. |
| 추가 기능 | 세 설정 비교·적용, 감정별 근거 탐색, 분석이 놓친 부분 카드, 작품·설정 공유, 행별 독자 메모를 제공합니다. |

최종 분석 다이어그램에서 실선은 실제 감지 시어와 감정의 연결이고 점선은 해석과 주제의 연결입니다. 프로필에서만 온 감정에는 가짜 시어 연결을 만들지 않습니다. 히트맵 색은 0~60%에서 진해지며 60% 이상은 같은 진하기입니다. 정확한 차이는 숫자로 확인합니다.

### 감정 이미지를 표현하는 방법

각 작품에는 사전에 제작한 수채화 대표 이미지 한 장이 있습니다. 감정 사전 반영 비율을 바꾸어도 그림은 동일하고, 감정 비율·추천·감성 지도는 선택한 반영 비율로 계산합니다. 대표 이미지는 기본 50%의 장면 규칙을 참고한 상징적 표현이며, 현재 선택한 분석 비율을 실시간으로 그린 결과가 아닙니다. 「절정」의 사전 100%처럼 감지가 없는 경우에도 대표 이미지는 표시하지만, 분석값이나 추천을 임의로 만들지 않습니다.

큰 창문·부드러운 패브릭 의자·작은 탁자와 감정별 인물 유무를 표현합니다. 실내 나무와 나뭇가지는 제외했습니다. 세부 자세·색 혼합량·소품이 감정 비율과 정확히 대응하는 것은 아니며, 시의 실제 장면이나 시인 초상을 재현한 그림도 아닙니다.

이미지는 `assets/poem-images/`에서 불러와 Canvas에 표시하며 PNG로 저장할 수 있습니다. 로딩에 실패하면 오류 안내를 표시합니다. 이미지와 같은 기본 50% 기준으로 장면 설명과 복사용 프롬프트를 제공합니다. 사이트에서 외부 이미지 생성 API를 호출하거나 사용자 입력을 전송하지 않습니다.

## 8. 확인한 환경과 검사 결과

Chromium 헤드리스에서 20편 × 반영 비율 11가지(0~100%, 10% 간격)의 220개 조건을 검사하여, 같은 작품의 이미지 픽셀이 동일하게 유지됨을 확인했습니다. 자체 점검 14/14, PNG 저장, 이미지 로딩 실패 안내와 390px 화면의 가로 넘침 없음도 확인했습니다. 검사 요약은 `assets/poem-images/validation.json`에 있습니다. 실제 휴대폰·Safari·화면 낭독기와 모든 기기 조합을 검사한 것은 아닙니다. 감정 비율과 문학적 해석의 정확도를 검증한 검사도 아닙니다.

## 9. 실행과 파일 구성

저장소에는 웹앱인 `index.html`, 이 문서인 `README.md`, 작품별 대표 이미지가 있는 `assets/poem-images/`를 함께 둡니다. 별도 빌드 과정이나 서버 설치는 없습니다. 로컬에서는 이미지 폴더를 포함한 파일들을 함께 내려받아 열 수 있으며, 제출용 주소는 GitHub Pages 주소를 사용합니다. 외부 API 키와 로그인은 필요하지 않습니다.

코드에서는 화면 스타일, 작품 데이터, 감정 사전, 분석 엔진, 그림 생성, 화면 동작을 나누어 관리합니다. 본문·사전·프로필을 바꾸면 비율뿐 아니라 추천·지도·이미지·검증 사례도 다시 확인해야 합니다.
